THE ORDER: 1886 FOR PC - WINDOWS COMPATIBILITY

This folder now contains both Linux and Windows versions of The Order 1886.

WINDOWS FILES:
- The Order 1886.exe (launcher with GUI)
- Play The Order 1886.exe (direct play)
- bin-windows/ (Windows runtime, launcher and 100+ DLLs)

LINUX FILES (original):
- The Order 1886 (launcher executable)
- Play The Order 1886 (direct play)
- bin/ (Linux runtime and libraries)

TO RUN ON WINDOWS:
1. Extract this entire folder to a writable location on Windows
2. Run "The Order 1886.exe" to open the launcher
3. Choose your extracted PS4 game folder (CUSA00076, CUSA00035, CUSA00070, 
   CUSA00070, CUSA00100, CUSA00670 or CUSA00785)
4. Press Play

REQUIREMENTS (Windows):
- Windows 10/11 x86-64
- Vulkan-compatible GPU with up-to-date drivers
- No Python or additional software required

SHARED FILES:
- user/ folder (settings, saves, logs) - shared between Linux and Windows
- scripts/ folder - Python scripts for both platforms
- Game content NOT included - you need your own PS4 dump

NOTES:
- Keep both .exe files and bin-windows/ together on Windows
- Keep both Linux executables and bin/ together on Linux
- The user/ folder is compatible between platforms
- Original game files are never modified

For full documentation, see README.md and QUICKSTART.txt
