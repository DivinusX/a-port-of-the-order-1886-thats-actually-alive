v0.2.62 is v0.2.61 with fixes for out-of-VRAM crashes during pipeline creation on 4 GB discrete GPUs. Saves and settings in `user/` are kept.

## What's fixed

### Pipeline `ErrorOutOfDeviceMemory` crash on 4 GB GPUs ([#73](https://github.com/DivinusX/a-port-of-the-order-1886-thats-actually-alive/issues/73))

On 4 GB cards such as the Radeon RX 580 4GB, the port could stop after a couple of minutes with `Failed to create graphics pipeline: ErrorOutOfDeviceMemory` (`vk_graphics_pipeline.cpp:522`). Several VRAM management paths worked against tight VRAM budgets:

- **Live VMA budget tracking was off:** VMA was created without `VMA_ALLOCATOR_CREATE_EXT_MEMORY_BUDGET_BIT`, so `VMA_ALLOCATION_CREATE_WITHIN_BUDGET_BIT` could not track live driver heap budgets.
- **Discrete GPUs kept startup GC thresholds:** texture-cache GC only refreshed against the driver's live heap budget on integrated GPUs or when overridden manually, missing runtime headroom drops from driver/shader allocations. Discrete GPUs now tighten GC thresholds dynamically against `70%` / `82%` / `90%` of the live budget while leaving large-VRAM GPUs unaffected unless squeezed.
- **Inverted LRU eviction age under pressure:** under VRAM pressure, the texture collector increased the minimum idle age (`160` / `80` instead of shrinking below `16`), preventing recently used textures from being evicted before VRAM ran dry. Age thresholds now shrink (`16` -> `8` -> `2`) and deletion limits widen (`10` -> `24` -> `64`) as pressure rises.
- **No VRAM reclaim before pipeline OOM:** graphics and compute pipeline creation now defers `ErrorOutOfDeviceMemory` long enough to drain pending GPU work/frees, evict idle textures from the cache, and retry synchronously (and buffer allocations get an over-budget fallback matching image allocations).

## Please test

- **#73:** if you play on a 4 GB GPU (RX 580 4GB or similar), try playing past the 2–3 minute mark where pipeline creation previously ran out of memory, and attach the newest `user/order1886/logs/*-boot.log` if another allocation error appears.

## Verification

Both packages build from the same commit in one release run (see `release-verification.json`); native checks, including new tests for 4 GB discrete texture-cache budget clamping (`texture-cache-budget-test`) and pipeline OOM propagation (`pipeline-binary-cache-test`), and the portable smoke ran in CI and in a local Linux Clang test build on an AMD Radeon RX 9070 XT.

**Not covered yet:** this release was not played end-to-end on physical 4 GB RX 580 hardware before release.
