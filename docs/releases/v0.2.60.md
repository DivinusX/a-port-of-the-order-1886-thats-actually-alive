v0.2.60 is v0.2.59 with a fix for a random crash with AMD FSR 4 upscaling, and F1 menu settings that are kept after you restart the game. Saves and settings in `user/` are kept.

## What's fixed

### Random crash with AMD FSR 4 ([#70](https://github.com/DivinusX/a-port-of-the-order-1886-thats-actually-alive/issues/70))

With **Upscaling → AMD FSR 4**, the game could stop after a few minutes with `Device lost during submit` (reported on an NVIDIA RTX 4070 SUPER). The port told FSR 4 that a frame was finished too early: it counted every frame shown since the game started, logos, menus and loading screens included, so FSR 4 reused the memory of the frame the GPU was still drawing. FSR 4 now frees a frame only after the GPU has actually finished it.

If you switched to FSR 3.1, DLAA or FSR 1 because of this crash, you can go back to FSR 4.

### F1 menu settings are kept after a restart

- **Closing the game with the F1 menu still open** no longer loses the changes you made in it.
- **Output resolution** chosen in F1 is now kept (it used to go back to the launcher's value).
- **Game frame rate** chosen in F1 is now kept for every choice. Before, only 30 and 60 FPS were kept. In the launcher, 90 FPS shows as 90 FPS; 120, 144 and 165 FPS show as Unlocked with the presentation frame cap at that rate; Unlocked shows as Unlocked with the highest cap (240).

Everything else in the F1 menu (window mode, V-Sync, upscaling, sharpening, render resolution, FPS counter, HDR, the quality settings and cinematic fill) was already kept.
