## What's new

### Surround sound ([#69](https://github.com/DivinusX/a-port-of-the-order-1886-thats-actually-alive/issues/69))

The game has its own 5.1 and 7.1 mix, as on the console, but until now the port always told it that only two speakers were connected, so it mixed for stereo and the centre, LFE and surround channels stayed silent. The port now tells the game how many speakers your default output device has:

- **7.1 or 5.1 speakers or receiver:** the game mixes for them: centre, subwoofer (LFE) and surrounds.
- **Stereo speakers and headphones:** no change; the game mixes for stereo as before.

**How to use it:** set your output device to 5.1 or 7.1 in Windows (**Sound settings → your device → Configure speakers**, or the speaker setup of your receiver's driver) before starting the game. The speaker layout is read when the game starts. The session log names it: `device 8 ch, game told 8 speakers`.

On Linux the default PipeWire or PulseAudio sink's channel count is used the same way.

## Verification

Both packages build from the same commit in one release run (see `release-verification.json`); native checks, including a new test of the speaker count, and the portable smoke ran on both. In a test build of the same change, the game's 8-channel output was recorded at the title screen: told 2 speakers, only front left and right carried sound; told 6, the centre, LFE and surrounds carried sound; told 8, the surrounds did.

**Not covered yet:** surround was not listened to on real 5.1 or 7.1 speakers, which side or back speakers the 7.1 surrounds use was not checked, and Linux was not run. The packaged v0.2.61 was not played before release.
