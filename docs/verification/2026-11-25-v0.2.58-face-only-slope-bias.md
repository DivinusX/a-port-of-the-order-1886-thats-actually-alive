# v0.2.58: slope redraw bias only on the player's face redraws (#67, #27)

Windows 11, RTX 5050 Laptop GPU, Chapter I (first building), November 25, 2026. Test builds from
`test/issue67-redraw-slope` (CI artifacts), run with the launcher's command line and settings
(`Test issue 67.ps1`, outside the repository) and `ORDER1886_REDRAW_LOG=1`.

## What the reports showed

The #67 follow-up videos (60 FPS phone recordings, game at 30 FPS) were decoded frame by frame.
The lattice window glass in the carpet room still changed in patches between frames on v0.2.57.
One video (first building) also lost the room's lighting on single frames, sometimes only right
of a vertical edge; that is not explained by the depth bias and was not reproduced here.

## Measurements

| Run | Slope bias goes to | Player face | Rugs at low angles |
|---|---|---|---|
| v0.2.57 values | every redraw (0.25) | clean | black patches jump in and out |
| slope off | nothing | spots | fixed |
| 4 face pipelines (round 6) | 4 face redraws | clean | fixed (5 min of play) |
| fragment programs only | 5 redraws (one extra, vs 193274a4) | clean | some rugs flicker |
| v0.2.58 rule | 4 face program pairs (log-confirmed) | clean | no flicker; occasional black rug |
| all redraw bias off | nothing (`ORDER1886_REDRAW_DEPTH_BIAS=0`) | spots | occasional black rug |

The occasional black rug happens with all redraw bias off, so it is a separate defect.

## Findings

- About 340 redraw pipelines run in Chapter I; restricting the bias by stage hash was unreliable
  because stage hashes carry a permutation index assigned in compile order (the same face
  pipeline was `52809520d29` in one session and `52809520d28` in the next).
- `Shader::Info::pgm_hash` is stable. The face redraws are the vertex+fragment pairs
  `527b7ca4+7f6a2e59`, `527b7ca4+3fec8179`, `e0ec7fe0+244bbb5e`, `e4fee1c+a54a188`.
  Vertex program `527b7ca4` is shared by well over a hundred other redraws, and fragment
  program `a54a188` also runs with vertex program `193274a4`, so both stages are matched.
- No redraw pipeline reports vertex formats on NVIDIA (dynamic vertex input and no fetch shader),
  so a "half-float vertex data" rule cannot select them.

## Not covered
